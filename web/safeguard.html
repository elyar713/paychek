How it works

Define rules once. Connect NinjaTrader. Choose Enabled when you want orders blocked — or stay in monitoring.

Enabled

Orders can be blocked

When Enabled and connected, Safeguard can block entries that break your rules — before they hit the market.

Disabled / not connected

Monitoring only

Rules and status still update. You see why a trade would be blocked or accepted — without enforcement.

  1. Set your rules

    Session, zones, lots, daily limits, cooldown, exit/SL — in the Safeguard app.

  2. Install the addon

    Close NinjaTrader → 2-Install-Addon.bat → F5. To remove: 4-Uninstall-Addon.bat → F5.

  3. Enable when ready

    Flip to Enabled for live protection. Status panel shows allowed vs blocked reasons.

Plan rules

Eight discipline controls — the same ones in the Safeguard app.

Session

Allow trading only inside your defined time window and timezone.

Trade zone

Entries outside your allowed price zones can be blocked.

Max lot

Cap size per entry so impulse cannot oversize the position.

Max trades / day

When the daily count is done, further entries stop.

Cooldown

Enforce a pause between trades so emotion cannot reopen risk.

Exit / SL discipline

Protect stop-loss behaviour — limit unsafe SL modifications.

Max loss / trade

Cap risk per trade; can close if floating loss exceeds the limit.

Max daily loss

Hard stop for the day when cumulative loss hits your ceiling.

Capital

Set account capital used as context for risk limits.

Usage hours

Define when you intend to trade — aligned with your session rules.

Status & reasons

Live status panel: Allowed / Blocked / Monitoring — with rule-by-rule reasons.
