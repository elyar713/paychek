Paychek Safeguard02

Produit

Qu’est-ce que Paychek Safeguard ?

Un garde-fou local : vos règles de discipline deviennent des contraintes techniques pendant le trading.

  • Définit les règles dans le logiciel Windows (Safeguard)
  • L’addon NinjaTrader applique / affiche le statut en temps réel
  • Si une règle est violée → trading blocked (ordres refusés quand Blocking on)
  • Fonctionne en local (127.0.0.1) — le PC doit rester allumé
Paychek Safeguard03

Architecture

Deux composants, un lien local

1. Logiciel Windows

UI Safeguard : plateforme, capital, usage hours, plan de règles, engage discipline, licence. Serveur local HTTP.

2. Addon NinjaTrader 8

Fenêtre Discipline : Connected, OK / BLOCKED, compteurs, Sync zones, Blocking on.

3. Lien temps réel

Webhooks / heartbeat sur 127.0.0.1:8080. Secret partagé. Sans Safeguard ouvert = pas de garde-fou.

Paychek Safeguard04

Installation

Kit Windows — 3 fichiers utilisateur

1

2-Install-Addon.bat

Ferme NT → installe les sources addon → rouvre NT → Compile (F5).

2

3-Open-Safeguard.bat

Démarre le serveur local + UI. Le serveur reste actif même si l’UI est fermée (STOP.bat pour arrêter).

3

NT → New → Paychek Safeguard

Fenêtre Discipline → Connected → activer licence PAYC → Engage discipline.

Paychek Safeguard06

Addon NinjaTrader

Fenêtre Discipline

  • Connected to Safeguard — lien actif
  • OK / BLOCKED — autorisé ou règle violée
  • Compteurs live : trades, intervalle, lot, session, daily loss
  • ADDON Blocking on — refus des ordres non conformes
  • Sync to Paychek — envoi des zones chart
  • Pinned / Refresh
Paychek Safeguard07

Discipline

Engage & niveaux

  • Strict — pas de désactivation avant l’heure limite (ex. 22:00)
  • Hybrid — désactivation après délai (ex. 20 min)
  • Tolerant — désactivation immédiate
  • Enabled = plan actif · Disabled = pause / monitoring

Paychek Safeguard09

Règle · Session

Fenêtre de trading

  • Heure début → fin (ex. 09:00 → 18:00)
  • Format 12h / 24h
  • Fuseau (ex. Europe/Paris)
  • Hors session → trading bloqué si Enabled
Paychek Safeguard10

Règle · Max trades

Quota de trades / jour

  • Max trades / day — plafond d’ouvertures (ex. 5)
  • Compteur Trades taken today + restants dans l’addon
  • Quota atteint → nouveaux trades bloqués
  • Anti-overtrading après une série
Paychek Safeguard11

Règle · Max lot

Taille maximale

  • Max lot size — plafond par entrée (ex. 3)
  • Empêche de « size up » émotionnellement
  • Visible dans NinjaTrader après Save / Enabled
  • Statut addon : Active · max N contract(s)
Paychek Safeguard12

Règle · Trade cooldown

Intervalle entre trades

  • Durée configurable (ex. 15 min)
  • After loss ou Every trade
  • Visible dans NinjaTrader après Save / Enabled
  • Anti revenge trading
Paychek Safeguard13

Règle · Max loss / trade

Risque par trade

  • Montant (€) + pourcentage (%)
  • Ex. 200 € · 10 % du capital
  • Avec Ninja + Enabled : ferme si perte flottante dépasse le seuil
Paychek Safeguard14

Règle · Max daily loss

Perte journalière max

  • Montant + % (ex. 400 € · 20 %)
  • Auto-calc possible (ex. 2 trades × 200 €)
  • Compteur live : Day’s loss vs Max
  • Seuil atteint → stop trading du jour
Paychek Safeguard15

Règle · Trade zone

Zone de prix sur le chart

  • Dessin de zone Paychek sur le chart NT
  • Sync to Paychek pour l’envoyer au logiciel
  • Hors zone → BLOCKED (prix outside trade zone)
  • Direction possible (ex. Sell only)
  • Live price affiché dans l’addon
Paychek Safeguard16

Règle · Exit / Stop loss

Stop losses synchronisés

  • Quota — nb de modifs SL (0 = verrouillé dès le départ)
  • Breakeven — après quota : SL seulement à BE ou mieux
  • Mode SL-only (pas de close manuel selon config)
Paychek Safeguard17

Réglages globaux

Capital & Usage hours

Capital

Montant de référence (ex. 2000 €) pour calculer les % de risque / daily loss.

Usage hours

Plage d’utilisation du logiciel (ex. 09:00–22:00), distincte de la session de trading.

Plateforme

Sélecteur NinjaTrader + indicateur Connected / Disconnected.

Auto-refresh

UI rafraîchit le statut périodiquement (ex. toutes les 30 s).

Paychek Safeguard18

Licence

Activation PAYC

  • Après achat, e-mail avec clé PAYC-… + date d’échéance
  • Saisir la clé dans Safeguard (1 PC)
  • Plans : essai / Lite / Pro (paychek.pro)
  • Actions : Upgrade, Clear license
  • Une nouvelle clé remplace l’essai précédent
Paychek Safeguard19

Usage

Workflow quotidien

2

Configurer le plan

3

4

Paychek Safeguard21

Avertissements

Précisions importantes

À lire avant utilisation
  • Pas un conseil en investissement — outil de discipline / risque.
  • Le trading comporte un risque de perte en capital.
  • Ne remplace pas broker, prop firm, ni risk management personnel.
  • Nécessite NT8 + Safeguard ouvert (serveur local).
  • Captures illustratives — l’UI peut évoluer.
  • Compatibilité / résultats non garantis (PC, data, VPS, version NT).
